# 要件ドキュメント

## 概要

Spirit of Kiroゲームにメール認証とパスワードリセット機能を追加します。現在のシステムでは、ユーザー登録時に自動的にアカウントが確認されていますが、セキュリティを向上させるため、メール認証による確認プロセスとパスワードリセット機能を実装します。

## 要件

### 要件1：メール認証機能

**ユーザーストーリー:** ゲームプレイヤーとして、アカウント登録時にメールアドレスを認証することで、アカウントのセキュリティを確保したい

#### 受け入れ基準

1. WHEN ユーザーがサインアップフォームでメールアドレスとパスワードを入力 THEN システムは確認メールを送信し、アカウントを未確認状態にする
2. WHEN ユーザーが確認メール内のリンクをクリック THEN システムはアカウントを確認済み状態に変更する
3. WHEN 未確認ユーザーがサインインを試行 THEN システムは「メール認証が必要です」エラーメッセージを表示する
4. WHEN 確認済みユーザーがサインインを試行 THEN システムは正常にログインを許可する
5. WHEN ユーザーが確認メールの再送信を要求 THEN システムは新しい確認メールを送信する

### 要件2：パスワードリセット機能

**ユーザーストーリー:** ゲームプレイヤーとして、パスワードを忘れた場合にメールを通じてパスワードをリセットできるようにしたい

#### 受け入れ基準

1. WHEN ユーザーがサインイン画面で「パスワードを忘れた」リンクをクリック THEN システムはパスワードリセット画面を表示する
2. WHEN ユーザーがパスワードリセット画面でメールアドレスを入力 THEN システムはパスワードリセット用のメールを送信する
3. WHEN ユーザーがパスワードリセットメール内のリンクをクリック THEN システムは新しいパスワード設定画面を表示する
4. WHEN ユーザーが新しいパスワードを入力して送信 THEN システムはパスワードを更新し、成功メッセージを表示する
5. WHEN パスワードリセットリンクが期限切れの場合 THEN システムは「リンクが期限切れです」エラーメッセージを表示する

### 要件3：メール送信システム

**ユーザーストーリー:** システム管理者として、ユーザーに確実にメールが届くよう、信頼性の高いメール送信システムを使用したい

#### 受け入れ基準

1. WHEN システムがメールを送信する必要がある THEN Amazon SESを使用してメールを送信する
2. WHEN メール送信が失敗した場合 THEN システムはエラーログを記録し、ユーザーに適切なエラーメッセージを表示する
3. WHEN 確認メールまたはパスワードリセットメールを送信 THEN メールにはゲームのブランディングと適切な件名を含める
4. WHEN メールテンプレートを使用 THEN HTMLとテキスト両方の形式でメールを送信する

### 要件4：セキュリティ強化

**ユーザーストーリー:** システム管理者として、メール認証とパスワードリセット機能が安全に実装されていることを確認したい

#### 受け入れ基準

1. WHEN 確認メールまたはパスワードリセットメールを生成 THEN トークンは暗号学的に安全でランダムである
2. WHEN 確認トークンまたはパスワードリセットトークンを生成 THEN トークンには適切な有効期限（24時間）を設定する
3. WHEN トークンが使用された場合 THEN システムはトークンを無効化し、再利用を防ぐ
4. WHEN 複数回のパスワードリセット要求がある場合 THEN システムはレート制限を適用する（1時間に3回まで）
5. WHEN 新しいパスワードを設定 THEN システムは既存のセッションを無効化する

### 要件5：ユーザーエクスペリエンス

**ユーザーストーリー:** ゲームプレイヤーとして、メール認証とパスワードリセットプロセスが分かりやすく、使いやすいものであってほしい

#### 受け入れ基準

1. WHEN ユーザーがサインアップを完了 THEN システムは「確認メールを送信しました」メッセージを表示する
2. WHEN ユーザーがパスワードリセットを要求 THEN システムは「パスワードリセットメールを送信しました」メッセージを表示する
3. WHEN メール認証またはパスワードリセットが成功 THEN システムは成功メッセージを表示し、適切な画面にリダイレクトする
4. WHEN エラーが発生した場合 THEN システムは分かりやすいエラーメッセージを日本語で表示する
5. WHEN ユーザーが確認メールの再送信を要求 THEN システムは再送信ボタンを提供し、適切なクールダウン時間を設ける
